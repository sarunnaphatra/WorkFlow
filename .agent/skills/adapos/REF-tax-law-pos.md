# กฎหมายเกี่ยวกับเอกสารภาษี ระบบ POS
> Reference Document สำหรับ AdaPos+ SKILL
> ที่มา: กรมสรรพากร / ประมวลรัษฎากร

---

## 1. หลักการพื้นฐาน VAT

### 1.1 รูปแบบการคิดภาษี
| รูปแบบ | เหมาะกับ | สูตร |
|--------|---------|------|
| **รวมภาษี (VAT Inclusive)** | ขายปลีก (End Customer) | `VAT = Amt - (Amt×100)/(100+VatRate)` |
| **แยกภาษี (VAT Exclusive)** | ขายส่ง (B2B) | `VAT = (Amt×(100+VatRate)/100) - Amt` |

> ⚠️ **ขายปลีกต้องใช้รวมภาษีเท่านั้น** ขายส่งเลือกได้ทั้งสองรูปแบบ

### 1.2 เงื่อนไขการออกใบกำกับภาษี
- ต้องเป็นผู้ **จดทะเบียน VAT** เท่านั้น
- รายได้เกิน **1.8 ล้านบาท/ปี** ต้องจดทะเบียน VAT (ทั้งบริษัทและบุคคล)

## 2. Tax Point (จุดเกิดภาษี)

| กรณี | Tax Point เกิดเมื่อ | ข้อยกเว้น (เกิดก่อนจะนับแทน) |
|------|-------------------|---------------------------|
| ขายสินค้าทั่วไป | ส่งมอบสินค้า | โอนกรรมสิทธิ์ / รับชำระ / ออกใบกำกับ |
| เช่าซื้อ/ผ่อนชำระ | ถึงกำหนดชำระแต่ละงวด | รับชำระ / ออกใบกำกับ |
| ส่งออก/นำเข้า | ชำระอากรขาออก/ขาเข้า | กรณียกเว้นอากร → วันออกใบขนสินค้า |
| บริการ | รับชำระค่าบริการ | ออกใบกำกับ / ใช้บริการแล้ว |

## 3. เอกสารประกอบการจ่ายภาษี
1. ใบกำกับภาษี
2. ใบเพิ่มหนี้ / ใบลดหนี้
3. รายงานภาษีขาย
4. รายงานภาษีซื้อ
5. รายงานสินค้าและวัตถุดิบ

---

## 4. ใบกำกับภาษีอย่างย่อ (ABB)

### เงื่อนไข
- ไม่ใช้เครื่องเก็บเงิน → ออกได้เลย
- ใช้เครื่องเก็บเงิน → **ต้องขึ้นทะเบียนกับสรรพากรก่อน**

### ข้อมูลที่ต้องมี
1. คำว่า **"ใบกำกับภาษีอย่างย่อ"**
2. ชื่อ/ชื่อย่อ + เลข 13 หลักของผู้ออก
3. เลขที่ใบกำกับภาษีอย่างย่อ
4. ชื่อ ชนิด ประเภท ปริมาณ มูลค่าสินค้า/บริการ (ออกเป็นรหัสได้)
5. ราคาสินค้า **ต้องระบุชัดเจนว่ารวม VAT แล้ว**
6. วัน เดือน ปี ที่ออก
7. ข้อความอื่นตามที่สรรพากรกำหนด

---

## 5. ใบคืน / ใบกำกับภาษีอย่างย่อ (CN-ABB)

### เงื่อนไข
- เงื่อนไขเดียวกับ ABB
- **ต้องอ้างอิงเลขที่ใบกำกับภาษีอย่างย่อ** ที่ต้องการคืน
- ข้อมูลที่ต้องมีเหมือน ABB ทุกข้อ

---

## 6. ใบกำกับภาษีเต็มรูป (Full Tax)

### ประเภทธุรกิจ
| ธุรกิจ | ชื่อเอกสาร |
|--------|-----------|
| ซื้อมา-ขายไป | ใบส่งของ / ใบกำกับภาษี |
| บริการ | ใบเสร็จรับเงิน / ใบกำกับภาษี |

### กฎสำคัญ
- ❌ **ไม่อนุญาตให้ออกใบกำกับภาษีข้ามวัน**
- ใช้ **วันที่ขาย** เป็นวันที่ออกใบกำกับภาษีเต็มรูป
- ขายสินค้า → ออกใบกำกับเมื่อส่งมอบ
- บริการ → ออกใบกำกับเมื่อรับเงิน

### ข้อมูลที่ต้องมี (8 รายการ)
1. คำว่า **"ใบกำกับภาษี"** เด่นชัด
2. เลขประจำตัวผู้เสียภาษีของผู้ขาย
3. ชื่อ ที่อยู่ของผู้ขาย
4. ชื่อ ที่อยู่ของผู้ซื้อ
5. หมายเลขลำดับใบกำกับภาษี (และเล่ม ถ้ามี)
6. วัน เดือน ปี ที่ออก
7. ชื่อ ชนิด ประเภท ปริมาณ มูลค่าสินค้า/บริการ
8. จำนวน VAT **แยกออกจากมูลค่าให้ชัดเจน**

---

## 7. การยกเลิกใบกำกับภาษีและออกใบใหม่

### เหตุที่ยกเลิกได้
- สาระสำคัญไม่ถูกต้อง เช่น ชื่อ/ที่อยู่ลูกค้าไม่ตรงที่จดทะเบียน

### ขั้นตอนในระบบ (AdaPos+)
```
Function > Cancel → ระบุเหตุผล → ยืนยัน
  ↓
ระบบ: เปลี่ยนสถานะเดิม → "CANCELLED"
ระบบ: สร้างเอกสารใหม่ (เลขที่ใหม่)
  - วันที่เอกสารใหม่ = วันที่เดิม (ตามกฎหมาย)
  - สถานะ = Open
  - แก้ไขได้: ข้อมูลสาระสำคัญ (ชื่อ/ที่อยู่)
  - แก้ไขไม่ได้: จำนวนเงิน
```

### กฎปฏิบัติ
| ขั้นตอน | ผู้ดำเนินการ | รายละเอียด |
|--------|------------|-----------|
| เรียกคืนต้นฉบับ | ร้านค้า | ประทับตรา "ยกเลิก" เก็บรวมกับสำเนา |
| ออกใบใหม่ | ร้านค้า | เลขที่ใหม่ วันที่เดิม มีหมายเหตุอ้างอิงฉบับเดิม |
| ถ่ายสำเนา | ลูกค้า | เก็บไว้เป็นหลักฐาน |
| บันทึกรายงานภาษีขาย | ร้านค้า | ระบุหมายเหตุทั้งใบเดิมและใบใหม่ |

### แนวทาง UI Design (AdaPos+)
```
[ปุ่มยกเลิก] → Popup: ระบุเหตุผล
  → [ยืนยัน]: ปรับสถานะ + Copy รายการ + เปิดเอกสารใหม่ (แก้สาระสำคัญได้ ยอดแก้ไม่ได้)
  → [ยกเลิก]: กลับหน้าเดิม
```

## 8. ใบแทนใบกำกับภาษีเต็มรูป

### เงื่อนไข
ออกเมื่อลูกค้าทำต้นฉบับ **สูญหาย / ถูกทำลาย / ชำรุดในสาระสำคัญ**

### Process (เหมือนการยกเลิก)
- ใช้ข้อมูลและรายการสินค้าเดิมทุกอย่าง
- บันทึกในรายงานภาษีขายเดือนที่ออกใบแทน

### ข้อมูลเพิ่มเติมในใบแทน
1. ใบแทนออกให้ครั้งที่
2. วัน เดือน ปี ที่ออกใบแทน
3. สาเหตุที่ออกใบแทน
4. ลายมือชื่อผู้ออกใบแทน

---

## 9. ใบลดหนี้ (Credit Note / CN)

### ผู้มีสิทธิ์ออก
- จดทะเบียน VAT และเคยออกใบกำกับภาษีแล้วเท่านั้น

### เหตุที่ออกได้
- ลดราคาสินค้า (ผิดข้อกำหนด/ชำรุด/ขาดจำนวน/คำนวณผิด)
- ลดราคาบริการ
- รับคืนสินค้า (ชำรุด/ไม่ตรงตัวอย่าง)
- คืนเงินมัดจำ เงินประกัน เงินจอง
- บอกเลิกสัญญาบริการ (บกพร่อง/ไม่ได้ให้บริการ)

### กฎการออก
- CN M:M Invoice → **1 ใบลดหนี้ อ้างได้หลายใบกำกับ**
- ควรออกในเดือนภาษีที่ซื้อ-ขาย (หากจำเป็น → ออกเดือนถัดไปได้)
- ต้องนำไปคำนวณ VAT ใหม่ในเดือนที่ออกใบลดหนี้

### ข้อมูลที่ต้องมี (11 รายการ)
1. คำว่า **"ใบลดหนี้"** เด่นชัด
2. ชื่อ ที่อยู่ เลขผู้เสียภาษีของผู้ขาย
3. ชื่อ ที่อยู่ของผู้ซื้อ
4. วัน เดือน ปี ที่ออก
5. เลขที่/เล่มที่ใบกำกับภาษีเดิม
6. มูลค่าตามใบกำกับเดิม
7. มูลค่าที่ถูกต้อง
8. ผลต่างของมูลค่า
9. จำนวน VAT ที่ลดลง
10. สาเหตุการออกใบลดหนี้
11. ข้อความอื่นตามอธิบดีกำหนด

---

## 10. ใบเพิ่มหนี้ (Debit Note / DN)

### ผู้มีสิทธิ์ออก
- จดทะเบียน VAT + เคยออกใบกำกับภาษีแล้ว + ต้องการแก้ไขราคาให้สูงขึ้น

### เหตุที่ออกได้
- สินค้าเกินจำนวนที่ตกลง
- คำนวณราคาต่ำกว่าที่เป็นจริง
- บริการเกินข้อกำหนด

### กฎการออก
- ออกในเดือนที่มีเหตุการณ์ (หากจำเป็น → เดือนถัดไป)
- นำ VAT ตามใบเพิ่มหนี้ไปรวมกับภาษีขายของตนในเดือนที่ออก

### ข้อมูลที่ต้องมี (8 รายการ)
1. คำว่า **"ใบเพิ่มหนี้"** เด่นชัด
2. ชื่อ ที่อยู่ เลขผู้เสียภาษีของผู้ออก
3. ชื่อ ที่อยู่ของผู้ซื้อ
4. วัน เดือน ปี ที่ออก
5. เลขที่/เล่มที่ใบกำกับภาษีเดิม
6. มูลค่าเดิม / มูลค่าที่ถูกต้อง / ผลต่าง / VAT ที่เพิ่ม
7. สาเหตุการออกใบเพิ่มหนี้
8. ข้อความอื่นตามอธิบดีกำหนด

---

## 11. ใบมัดจำ (Deposit Invoice)

### เงื่อนไข
- ผู้จดทะเบียน VAT ต้องออกใบกำกับภาษีทุกครั้งที่รับมัดจำ
- Tax Point = วันที่รับเงินมัดจำ
- ยกเว้น: กรณีที่จะคืนเงินมัดจำ (เช่น มัดจำภาชนะ) → ไม่ต้องออก

### ข้อมูลที่ต้องมี
เหมือนใบกำกับภาษีเต็มรูป (8 รายการ) ทุกข้อ รวมถึงการแยก VAT ให้ชัดเจน

---

## 12. ใบหักภาษี ณ ที่จ่าย (Withholding Tax)

### อัตราหัก ณ ที่จ่าย
| ประเภทบริการ | อัตรา |
|------------|------|
| ขนส่ง | 1% |
| โฆษณา | 2% |
| บริการทั่วไป | 3% |
| ค่าเช่า | 5% |

### เงื่อนไข
- ไม่หัก สำหรับยอด **ไม่เกิน 1,000 บาท**
- แบบฟอร์ม: บุคคลธรรมดา → **ภ.ง.ด.3** | นิติบุคคล → **ภ.ง.ด.53**
- ออก 2 ฉบับ: ฉบับที่ 1 (แนบแสดงรายการ) + ฉบับที่ 2 (เก็บเป็นหลักฐาน)

### ข้อมูลที่ต้องมี
1. ชื่อ-ที่อยู่-เลขผู้เสียภาษีของ **ผู้จ่ายเงิน**
2. ชื่อ-ที่อยู่-เลขผู้เสียภาษีของ **ผู้รับเงิน**
3. วัน เดือน ปี ที่จ่ายเงิน
4. จำนวนเงินที่จ่าย + จำนวนภาษีที่หักนำส่ง
5. ลายมือชื่อผู้จ่ายเงิน + วัน เดือน ปี + ตรานิติบุคคล (ถ้ามี)

---

## 13. สรุป Business Rules สำหรับ AdaPos+

```
✅ ต้องทำ:
- ABB: ออกทันทีหลังขาย
- Full Tax: ออกวันเดียวกับวันขาย (ห้ามข้ามวัน)
- ใบมัดจำ: ออกทุกครั้งที่รับเงิน (Tax Point = รับเงิน)
- ยกเลิกใบกำกับ: เลขใหม่ วันที่เดิม มีหมายเหตุ
- CN/DN: บันทึกรายงานภาษีขายเดือนที่ออก

⚠️ ระวัง:
- ห้ามออก Full Tax ข้ามวัน
- CN สามารถอ้างได้หลายใบกำกับ (M:M)
- WHT ต่ำกว่า 1,000 บาท ไม่ต้องหัก
- ผู้ไม่ได้จด VAT ห้ามออกใบกำกับ/CN/DN

❌ ห้าม:
- แก้ไขจำนวนเงินบนใบกำกับที่ออกแล้ว
- ออกใบกำกับย้อนหลัง (ต้องทำ Void + ออกใหม่วันที่เดิม)
```
