# 🛠️ Development Flow with Trae

ขั้นตอนมาตรฐานในการพัฒนาฟีเจอร์ใหม่หรือแก้ไข Bug โดยใช้พลังของ AI

## 📋 ขั้นตอนการทำงาน (Standard Flow)

### 1. การวางแผน (Planning)
- ใช้ **Chat Mode** ปรึกษาแนวทางการแก้ไข
- **Prompt**: "ฉันต้องการเพิ่มระบบตะกร้าสินค้า ต้องแก้ไขไฟล์ไหนบ้าง และมีขั้นตอนอย่างไร?"
- AI จะเสนอแผนงานและรายการไฟล์ที่ต้องเกี่ยวข้อง

### 2. การสร้าง/แก้ไขโค้ด (Implementation)
- **สร้างไฟล์ใหม่**: สั่ง AI ใน Builder Mode "สร้าง Component Button ใหม่ที่..."
- **แก้ไขโค้ดเดิม**: ใช้ **Inline Edit (Ctrl + I)** เพื่อเปลี่ยน Logic เฉพาะจุด
- **Prompt Tip**: ระบุ Style หรือ Library ที่ต้องการให้ชัดเจน เช่น "ใช้ TypeScript และเน้น Clean Code"

### 3. การตรวจสอบคุณภาพ (Quality Assurance)
- **หาข้อผิดพลาด**: "ช่วยตรวจสอบไฟล์นี้ว่ามีจุดไหนเสี่ยงต่อ Security หรือ Performance หรือไม่?"
- **เขียน Test**: "ช่วยเขียน Unit Test สำหรับฟังก์ชันนี้โดยใช้ Vitest"

### 4. การจัดการข้อผิดพลาด (Debugging)
- หากรันแล้วเจอ Error ให้ Copy Error Message มาวางใน Chat
- หรือกดปุ่ม **"Debug with AI"** ที่ขึ้นใน Terminal เมื่อเกิด Error
- AI จะวิเคราะห์สาเหตุและเสนอวิธีแก้ (Fix suggestions)

## 🎯 เคล็ดลับเพิ่มความเร็ว (Pro Tips)
- **Use Mentions**: ใช้ `@` เพื่อระบุ Context เช่น `@Files`, `@Terminal`, `@Web`
- **Iterative Refinement**: ถ้า AI ทำไม่ถูกใจ ให้สั่งแก้ต่อทีละนิด "เปลี่ยนสีปุ่มเป็นสีฟ้าเข้มกว่านี้"
- **Documentation**: สั่ง AI เขียน Comment หรือ JSDoc ให้ทันทีหลังเขียนโค้ดเสร็จ

## 🔄 วนซ้ำ (Repeat)
- ทำงานทีละ Task เล็กๆ (Atomic) 
- Commit งานบ่อยๆ เพื่อให้มีประวัติการเปลี่ยนแปลงที่ชัดเจน
